## Overview

**Kālai** is a ceramic piece lifecycle and studio management application for ceramic artists to track work through multi-stage firings, glazes, clay bodies, and pyrometric cone schedules.

> [!NOTE]  
> This codebase is under heavy active development.

## Tech Stack

- **Framework:** Svelte 5 + SvelteKit
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Database:** Supabase
- **Icons:** Lucide Svelte

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run type checks
npm run check

# Build for production
npm run build
```
